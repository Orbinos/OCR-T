# Shortcut

Install the current shared OCR-T shortcut from:

https://www.icloud.com/shortcuts/c40f71394eab4ec9ba93325296b9ab35

The repository's reviewable source components live in `../scripts/`, and the exact action order is documented in `../docs/ARCHITECTURE.md`.

## Optional binary export

For a fully self-contained repository, export the shortcut from the macOS Shortcuts app and place the exported file here as:

```text
OCR-T.shortcut
```

The iCloud share URL remains the convenient installation path for end users.
